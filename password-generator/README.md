# Batch password generator

**2000s · Windows batch scripting**

A Windows batch utility for generating passwords with configurable length and character classes. Menu-driven settings control the generation process, with results written to a text file.

## Original file

[password-gen.bat](originals/password-gen.bat)

The complete script is retained in its original encoding and line endings. Its banner credits **SwYaraB**, preserved as written.

The script records a period approach to interactive batch programming using variables, conditional branches, labels, and loops.
