# Web security research: SQL injection

**Circa 2007–2008 · Independent web security research**

Around 2007–2008, I independently investigated web applications using SQL injection. This work explored how weaknesses in the handling of application input could expose database contents. The original database files kept with this project are retained results of that research.

## Research focus

- SQL injection in web applications.
- The relationship between application input and database query behavior.
- Database information exposed during the investigations.
- Preserving the original results for later study.

## Method and outcome

The research method was SQL injection, as recalled by me when preparing this retrospective. The archived outputs are kept alongside the write-up in their original form. The approximate dates also come from my recollection.

The specific injection techniques, tools, and sequence of each investigation can be described as those details are reconstructed. No particular payload, tool, or injection subtype is assigned here.
