# RapidShare account finder

**2000s · Visual Basic 6**

A small account-checking application that loads identifiers into a list, sends requests, and updates the displayed status from the responses.

- [Complete original files](originals/)
- [VB6 project](originals/RapidShare.vbp)

The source, inputs, and project files remain unchanged. This work records early experimentation with text-file loading, list-view controls, iteration, and request/response handling.
